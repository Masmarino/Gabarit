# RGAA Audit — Checkbox

Verified against RGAA 4.1.2 by exercising `Atoms/Checkbox` in
Storybook (stories `Unchecked`, `Checked`, `Disabled`, `Dark`) and by
code review (`checkbox.ts`, `checkbox.html`, `checkbox.scss`).

| Criterion   | Short title                             | Verification                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Result                                                   |
| ----------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------- |
| 3.1         | Information not conveyed by color alone | The checked state is carried by the browser's native rendering (filled box + graphic checkmark), not by `accent-color` alone — the shape changes, not just the hue.                                                                                                                                                                                                                                                                                                                                                                                          | Compliant                                                |
| 3.2         | Text contrast                           | Covered by `contrast.spec.ts` (`--text-primary` on `--bg-principal`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Compliant (delegated)                                    |
| 3.3         | Component contrast                      | Native browser rendering for the box itself (outside the component's direct CSS control, depends on the rendering engine/OS). `accent-color: var(--primary)` sets the checked hue.                                                                                                                                                                                                                                                                                                                                                                           | Compliant (delegated to native rendering)                |
| 7.3         | Keyboard- and pointer-operable          | Native `<input type="checkbox">` — Space toggles the state by browser default, no `keydown` handler in `checkbox.ts` intercepts it. `onToggle` reacts to the `change` event, fired by both keyboard and mouse.                                                                                                                                                                                                                                                                                                                                               | Compliant (code review)                                  |
| 10.7        | Visible focus indicator                 | No `outline` rule in `checkbox.scss`: the browser's default focus outline on the native box stays active, not suppressed.                                                                                                                                                                                                                                                                                                                                                                                                                                    | Compliant (code review — default outline not suppressed) |
| 10.11       | 320px reflow                            | Viewport set to 320×600 on `Unchecked`: no horizontal scroll.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Compliant — verified                                     |
| 10.12       | Redefinable text spacing                | Injected stylesheet (`line-height:1.5`, `letter-spacing:0.12em`, `word-spacing:0.16em`) on `Unchecked`: the label stays readable and aligned, screenshot on file.                                                                                                                                                                                                                                                                                                                                                                                            | Compliant — verified                                     |
| 11.1        | Label presence                          | `label()` rendered inside a `<span>` within the enclosing `<label>` (implicit `[for]` via nesting, not an explicit `id`/`for`) — if `label` is left empty, the `<span>` is empty and the box loses its accessible name: the consumer's responsibility.                                                                                                                                                                                                                                                                                                       | Compliant when `label` is provided                       |
| 11.2        | Label relevance                         | Text entirely delegated to the consumer — nothing to check on the component's side.                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Compliant (delegated)                                    |
| 11.4        | Label position                          | `<span>` after `<input>` in the flow — the conventional position for a checkbox (unlike `input`, where the label precedes the field).                                                                                                                                                                                                                                                                                                                                                                                                                        | Compliant                                                |
| WCAG 2.5.8  | 24×24px target size                     | The native checkbox box alone is 16×16px, but the actual clickable area is the whole `<label>` (clicking anywhere inside it activates the box, via `<label>`'s native behavior). Since `<input>` is a replaced element and can't carry its own generated `::before`, `.gbt-checkbox` (the label) carries an absolutely-positioned, centered `::before` sized to `max(100%, 24px)`, extending the target area to at least 24×24px with no change to the visible rendering. Measured in Storybook (`getComputedStyle(label, '::before')`): **185.852 × 24px**. | Compliant                                                |
| WCAG 2.4.11 | Focus not obscured                      | No scrolling container specific to the component.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Not applicable to this component                         |

Dark mode is visually confirmed in Storybook: on the `Dark` story,
with `data-theme="dark"` set, `body` renders `rgb(13, 27, 36)` and the
label `rgb(247, 249, 251)`, measuring **16.59:1**. Token contrast is
otherwise covered by `contrast.spec.ts`, independently of this
rendering.
