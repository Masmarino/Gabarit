# RGAA Audit — ListCard

Verified against RGAA 4.1.2 by exercising `Molecules/ListCard` in
Storybook (stories `Ready`, `WithHeading`, `NoResultsInTab`, `Loading`,
`LoadingThenReady`, `Failed`, `FailedWithCustomAction`, `Empty`,
`EmptyWithIllustration`, `Narrow`, `NarrowStates`, `Dark`) and by code
review (`list-card.ts`, `list-card.html`, `list-card.scss`).

The header is a plain row **above** the card's box (no background, border or
padding of its own, as `gbt-card`'s), but — unlike `gbt-card` — it stays
inside the card's `<section>`: the section wraps the status, the header and
the box, and only the box draws the edge.

## Externalized strings

`loadingLabel`, `failedHeading`, `failedMessage`, `retryLabel`, `emptyHeading`
and `emptyMessage` are inputs with English defaults, to be localised by the
application.

Dark mode is visually confirmed in Storybook (`Dark` story: the four states).
