# RGAA Audit — CheckboxGroup

Verified against RGAA 4.1.2 by exercising `Molecules/CheckboxGroup` in Storybook (stories
`Nominal`, `WithHintAndOptionHints`, `GroupedColumns`, `TwoColumns`, `WithError`, `Disabled`,
`HiddenLegend`, `Dark`) and by code review (`checkbox-group.ts`, `checkbox-group.html`,
`checkbox-group.scss`). Each box is the existing `gbt-checkbox` (native `<input type="checkbox">`).

## Checklist

| Criterion     | Short title                                  | Verification                                                                                                                                                                                                                                                                                                                                            | Result                  |
| ------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| 3.1           | Information not conveyed by color alone      | Checked state is the browser's native box + checkmark (shape, not hue alone); an error is a text message with `role="alert"`, not only a colour.                                                                                                                                                                                                        | Compliant               |
| 3.2           | Text contrast                                | Legend `--text-secondary`, group headings `--text-primary`, hint `--text-secondary`, error `--color-error-text`, all on the page background — covered by `contrast.spec.ts` in both themes.                                                                                                                                                             | Compliant (delegated)   |
| 7.1           | Scripts compatible with assistive technology | No ARIA reimplementation of the checkbox: native inputs in a `fieldset`. 0 axe violations flat, sectioned, with hint/required/disabled, with error and hidden legend (`checkbox-group.spec.ts`).                                                                                                                                                        | Compliant               |
| 7.3           | Keyboard- and pointer-operable               | Every box is a native tab stop (`tabIndex 0`), Space toggles by browser default; no `keydown` handler swallows it (tested: an unprevented Space event, label click = box click).                                                                                                                                                                        | Compliant               |
| 10.7          | Visible focus indicator                      | Native focus outline of each checkbox kept (not suppressed in `checkbox.scss`).                                                                                                                                                                                                                                                                         | Compliant (code review) |
| 10.11         | 320px reflow                                 | Grid columns are `minmax(0, 1fr)` (fixed count) or `auto-fill, minmax(11rem, 1fr)` (`'auto'`): no horizontal scroll at 375 px (verified in Storybook, `GroupedColumns`). Only `columns="auto"` collapses to one column on a narrow screen; a fixed count (`columns="3"`) keeps N equal columns and wraps long labels, so use it only for short options. | Compliant — verified    |

| 11.2          | Label relevance                              | Texts are the consumer's. The legend is the shared question, announced with each box by screen readers.                                                                                                                                                                                                                                                 | Compliant (delegated)   |

| 11.10 / 11.11 | Input error message, suggestions             | `errorMessage` is rendered as `role="alert"`, linked by `aria-describedby`, with `aria-invalid="true"` on the fieldset; the hint gives way to it so only one description exists.                                                                                                                                                                        | Compliant               |
| WCAG 2.5.8    | 24×24px target size                          | Each box keeps `gbt-checkbox`'s `::before` 24 px minimum target area (audited in `checkbox/AUDIT.md`); rows are spaced 0.5rem apart.                                                                                                                                                                                                                    | Compliant               |

## Notes

- `required` only adds ` *` to the legend (like `RadioGroup`); `aria-required` is not valid on a
  `group`, so requiredness is expressed by the error message the consumer's validation produces.
- No roving tabindex on purpose: checkboxes are independent controls (APG "checkbox" pattern),
  unlike a radio group or the segmented control.
- Externalized strings: none — legend, labels, hint and error all come from the consumer.
