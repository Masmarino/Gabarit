# Gabarit 0.2 — Tranche 3 : les trois graphiques cartésiens — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer `gbt-line-chart`, `gbt-bar-chart` et `gbt-timeline-chart` — les premiers composants de la couche dataviz qu'une application peut poser dans une page.

**Architecture:** Chaque graphique se compose de deux composants : une enveloppe, qui calcule ses domaines depuis ses données et assemble le socle, et un tracé à sélecteur d'attribut, **projeté** dans `[gbtChartLayer]`, qui lit les échelles dans le contexte et engendre les chemins. Cette séparation n'est pas une élégance : le contexte n'est accessible qu'aux composants projetés dans le socle, jamais à celui qui l'enveloppe.

**Tech Stack:** Angular 22 (standalone, `input()`, `computed()`, `OnPush`, composants génériques comme `Table<T>`), vitest via `@angular/build:unit-test`, `axe-core`, Storybook `@storybook/angular-vite`. Aucune dépendance ajoutée.

**Spec:** `docs/superpowers/specs/2026-08-30-gabarit-0.2-tranche-3-cartesiens-design.md`

## Global Constraints

- **Aucune dépendance runtime nouvelle.** La librairie ne dépend que de `tslib`.
- **Aucune chaîne visible en dur.** Toute chaîne affichée est une entrée de composant, y compris celles destinées aux lecteurs d'écran — l'audit de la 0.1 en a laissé passer trois, cachées dans un `sr-only` et un `[attr.aria-label]`.
- **La locale est toujours un paramètre**, jamais déduite de l'environnement.
- **Sélecteurs en `gbt-`, classes BEM internes en `gbt-`.**
- **`ChangeDetectionStrategy.OnPush`** sur tous les composants.
- **Tous les composants vivent sous `projects/gabarit/src/lib/components/`** — `token-usage.spec.ts` ne parcourt que ce répertoire, et un composant placé ailleurs échapperait au garde de tokens.
- **Un token `*-base` ne peint jamais de texte.** Les couleurs de série sont validées à 3:1 ; un garde les refuse sur toute règle dont le sélecteur désigne du texte, `fill` comme `stroke`.
- **Les couleurs se posent en CSS, jamais en attribut de présentation SVG.** Un `stroke="var(--x)"` ne résout pas la variable et sort noir ; le garde de tokens ne lit d'ailleurs que les feuilles de style.
- **Les identifiants employés dans une expression de gabarit ne portent pas d'accent.** Le lexer d'Angular les rejette — `NG5002: Lexer Error: Unexpected character [é]` — contrairement à TypeScript, qui les accepte. Mesuré par sonde le 30/08/2026. Les commentaires et les intitulés de test, eux, restent accentués.
- **Les éléments SVG d'un gabarit sans balise `<svg>` dans le même fichier portent le préfixe `svg:`** — `<svg:g>`, `<svg:path>`. Angular résout l'espace de noms lexicalement, par gabarit ; sans le préfixe la compilation échoue en `NG8001`.
- **Un bloc `@if` qui projette dans une fente nommée n'a qu'un seul nœud racine.** Au-delà, Angular n'émet qu'un **avertissement** `NG8011` et le contenu **n'est pas projeté du tout** — mesuré par sonde : deux tables déclarées dans un `@if` imbriqué rendent zéro table, sans qu'aucun test n'échoue par lui-même. Un graphique perdrait ainsi sa table `sr-only`, donc son chemin non visuel, en silence. Écrire des `@if` frères à racine unique plutôt qu'imbriqués.
- **Une brique destinée à vivre dans `[gbtChartLayer]` porte un sélecteur d'attribut sur un `g`**, jamais un sélecteur d'élément — un élément personnalisé hériterait de l'espace de noms SVG, où il serait inconnu, donc non rendu avec tout son contenu.
- Commits en français, format Conventional Commits.
- **Intitulés de test et commentaires en français accentué.**

## Ce que la mesure a imposé, et que la spec porte désormais

Deux contraintes découvertes en sondant le socle, qui décident de toute la structure.

**Un graphique enveloppe le socle : il en est l'ancêtre, donc il ne peut pas injecter le contexte que le socle fournit à ses descendants.** Sondé : un composant déclaré dans le gabarit du graphique puis _projeté_ dans le socle lit correctement le contexte — `innerWidth` mesuré à 544 pour un socle de 600 px moins ses marges de 48 et 8. C'est la projection qui donne l'accès, pas la parenté.

**L'infobulle ne peut donc recevoir ni sa position ni son contenu depuis le graphique.** Les deux dépendent de l'index actif, que seul le contexte porte. Son entrée `x` en pixels et son `<ng-content>` disparaissent au profit d'un tableau de points pré-formatés qu'elle indexe elle-même.

`chart-tooltip.ts` :

```typescript
import { ChangeDetectionStrategy, Component, computed, inject, input } from '@angular/core'
import { CHART_CONTEXT } from '../chart-context/chart-context'
import type { BandScale, Scale } from '../../primitives'

export interface TooltipRow {
  label: string
  value: string
}

/** Un point du graphique, tel que l'infobulle doit l'afficher. */
export interface TooltipPoint<X> {
  /** Abscisse dans le domaine — sert au positionnement, pas à l'affichage. */
  x: X
  /** Titre de l'infobulle : l'abscisse déjà formatée par le graphique. */
  header: string
  rows: TooltipRow[]
}

/**
 * Panneau d'information du point actif.
 *
 * Il ne porte **aucune logique clavier** : `gbt-chart-frame` possède
 * l'interaction, cette brique n'en affiche que le résultat.
 *
 * Il reçoit des points déjà formatés plutôt qu'un contenu projeté, et
 * calcule sa position lui-même. Ce n'est pas un choix de commodité : un
 * graphique *enveloppe* le socle, donc n'injecte pas le contexte que celui-ci
 * fournit à ses descendants. Ni l'index actif, ni les échelles, ni les marges
 * ne lui sont accessibles. L'infobulle, elle, est projetée — elle les lit.
 */
@Component({
  selector: 'gbt-chart-tooltip',
  standalone: true,
  imports: [],
  templateUrl: './chart-tooltip.html',
  styleUrl: './chart-tooltip.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class ChartTooltip<X> {
  points = input.required<TooltipPoint<X>[]>()

  private readonly context = inject(CHART_CONTEXT)

  /**
   * Le socle ne connaît que `pointCount` : rien ne garantit qu'il
   * corresponde à la longueur du tableau reçu. Un index hors bornes
   * n'affiche rien plutôt que de lire `undefined`.
   */
  protected readonly active = computed<TooltipPoint<X> | null>(() => {
    const index = this.context.activeIndex()
    if (index === null) return null
    return this.points()[index] ?? null
  })

  /** Position en pixels dans le repère externe du socle, marge comprise. */
  protected readonly left = computed(() => {
    const point = this.active()
    if (point === null) return 0
    const kind = this.context.xSpec().kind
    const scale = this.context.xScale()
    const inner =
      kind === 'band'
        ? (scale as BandScale).map(point.x as unknown as string) +
          (scale as BandScale).bandwidth / 2
        : (scale as Scale<number> | Scale<Date>).map(point.x as never)
    return inner + this.context.box().margin.left
  })
}
```

```typescript
import {
  longestSeriesLength,
  numericXDomain,
  timeXDomain,
  yDomain,
  type ChartSeries,
} from './chart-data'

const serie = (label: string, ys: number[]): ChartSeries<number> => ({
  label,
  points: ys.map((y, i) => ({ x: i, y })),
})

describe('yDomain', () => {
  it('couvre toutes les séries, pas seulement la première', () => {
    expect(yDomain([serie('a', [1, 5]), serie('b', [-3, 9])], false)).toEqual([-3, 9])
  })

  // Un axe qui ne part pas de zéro exagère les variations : le défaut d'une
  // librairie doit être honnête, et qui veut tronquer le dit.
  it('étend jusqu’à zéro quand on le demande', () => {
    expect(yDomain([serie('a', [10, 20])], true)).toEqual([0, 20])
  })

  it('étend vers le bas quand les valeurs sont négatives', () => {
    expect(yDomain([serie('a', [-10, -2])], true)).toEqual([-10, 0])
  })

  it('ne tronque pas quand on ne le demande pas', () => {
    expect(yDomain([serie('a', [10, 20])], false)).toEqual([10, 20])
  })

  // Sans domaine, le socle ne peut construire aucune échelle et l'axe
  // disparaît. Un intervalle unitaire rend un axe vide mais lisible.
  it("d'aucune série, rend un intervalle unitaire plutôt qu'un domaine vide", () => {
    expect(yDomain([], true)).toEqual([0, 1])
    expect(yDomain([{ label: 'vide', points: [] }], true)).toEqual([0, 1])
  })

  it("d'une valeur unique, rend un domaine non plat", () => {
    // Un domaine plat projetterait tous les points au même pixel.
    const [min, max] = yDomain([serie('a', [7])], false)
    expect(max).toBeGreaterThan(min)
  })
})

describe('numericXDomain', () => {
  it('couvre les abscisses de toutes les séries', () => {
    const a: ChartSeries<number> = {
      label: 'a',
      points: [
        { x: 5, y: 0 },
        { x: 9, y: 0 },
      ],
    }
    const b: ChartSeries<number> = { label: 'b', points: [{ x: 1, y: 0 }] }
    expect(numericXDomain([a, b])).toEqual([1, 9])
  })

  it("d'aucun point, rend un intervalle unitaire", () => {
    expect(numericXDomain([])).toEqual([0, 1])
  })
})

describe('timeXDomain', () => {
  it('couvre les instants de toutes les séries', () => {
    const a: ChartSeries<Date> = {
      label: 'a',
      points: [
        { x: new Date('2026-03-02T00:00:00Z'), y: 0 },
        { x: new Date('2026-03-05T00:00:00Z'), y: 0 },
      ],
    }
    const [debut, fin] = timeXDomain([a])
    expect(debut.toISOString()).toBe('2026-03-02T00:00:00.000Z')
    expect(fin.toISOString()).toBe('2026-03-05T00:00:00.000Z')
  })

    expect(longestSeriesLength([serie('a', [1, 2]), serie('b', [1, 2, 3, 4])])).toBe(4)
  })

  it("d'aucune série, rend zéro", () => {
    expect(longestSeriesLength([])).toBe(0)
```

```typescript
export interface ChartPoint<X> {
  x: X
  y: number
}

export interface ChartSeries<X> {
  label: string
  points: ChartPoint<X>[]
  /** Second signal, non coloré — même vocabulaire que `LegendEntry`. */
  pattern?: 'solid' | 'dashed' | 'dotted'
}

/** Intervalle marqué sur un axe temporel. Le composant ignore ce qu'il représente. */
export interface ChartInterval {
  start: Date
  end: Date
  label: string
}

const DAY = 86400000

/**
 * Domaine des ordonnées couvrant toutes les séries.
 *
 * `includeZero` étend jusqu'à l'origine : un axe tronqué exagère les
 * variations, et le défaut d'une librairie doit être honnête.
 */
export function yDomain<X>(series: ChartSeries<X>[], includeZero: boolean): [number, number] {
  const values = series.flatMap((s) => s.points.map((p) => p.y))
  // Sans donnée, le socle ne pourrait construire aucune échelle et l'axe
  // disparaîtrait. Un intervalle unitaire rend un axe vide mais lisible.
  if (values.length === 0) return [0, 1]

  let min = Math.min(...values)
  let max = Math.max(...values)
  if (includeZero) {
    min = Math.min(min, 0)
    max = Math.max(max, 0)
  }
  // Un domaine plat projetterait tous les points au même pixel.
  if (min === max) return [min, min + 1]
  return [min, max]
}

export function numericXDomain(series: ChartSeries<number>[]): [number, number] {
  const values = series.flatMap((s) => s.points.map((p) => p.x))
  if (values.length === 0) return [0, 1]
  const min = Math.min(...values)
  const max = Math.max(...values)
  return min === max ? [min, min + 1] : [min, max]
}

export function timeXDomain(series: ChartSeries<Date>[]): [Date, Date] {
  const values = series.flatMap((s) => s.points.map((p) => p.x.getTime()))
  // Une valeur arbitraire mais déterministe : `new Date()` rendrait le
  // résultat dépendant de l'heure d'exécution, donc les tests fragiles.
  if (values.length === 0) return [new Date(-DAY), new Date(0)]
  const min = Math.min(...values)
  const max = Math.max(...values)
  return min === max ? [new Date(min), new Date(min + DAY)] : [new Date(min), new Date(max)]
}

/** Nombre de points que le socle doit rendre navigables au clavier. */
export function longestSeriesLength<X>(series: ChartSeries<X>[]): number {
  return series.reduce((longest, s) => Math.max(longest, s.points.length), 0)
}
```

```typescript
import { ChangeDetectionStrategy, Component, computed, inject, input } from '@angular/core'
import { CHART_CONTEXT } from '../chart-context/chart-context'
import { areaPath, linePath, type Scale } from '../../primitives'
import type { ChartSeries } from '../chart-data/chart-data'

interface RenderedSeries {
  label: string
  ligne: string
  aire: string
  /** 1, 2 ou 3 — la palette cycle au-delà, elle ne tronque pas. */
  couleur: number
  tiretage: string
}

const DASH_ARRAYS: Record<NonNullable<ChartSeries<unknown>['pattern']>, string> = {
  solid: 'none',
  dashed: '6 3',
  dotted: '1 3',
}

/**
 * Tracé des courbes. Composant **projeté** dans `[gbtChartLayer]`, et c'est
 * ce qui lui donne accès au contexte : `gbt-line-chart` enveloppe le socle,
 * il en est l'ancêtre, et ne pourrait donc pas l'injecter.
 *
 * Sélecteur d'attribut sur un `g` : un élément personnalisé hériterait de
 * l'espace de noms SVG, où il serait inconnu, donc non rendu.
 */
@Component({
  selector: 'g[gbtLineSeries]',
  standalone: true,
  imports: [],
  templateUrl: './line-series.html',
  styleUrl: './line-series.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: { 'aria-hidden': 'true' },
})
export class LineSeries<X> {
  series = input.required<ChartSeries<X>[]>()
  area = input(false)

  private readonly context = inject(CHART_CONTEXT)

  protected readonly traces = computed<RenderedSeries[]>(() => {
    const x = this.context.xScale() as Scale<never>
    const y = this.context.yScale()
    const base = this.context.box().innerHeight

    return this.series().map((serie, index) => {
      const points = serie.points.map((p) => ({
        x: x.map(p.x as never),
        y: y.map(p.y),
      }))
      return {
        label: serie.label,
        ligne: linePath(points),
        aire: areaPath(points, base),
        couleur: (index % 3) + 1,
        tiretage: DASH_ARRAYS[serie.pattern ?? 'solid'],
      }
    })
  })
}
```

```typescript
import { ChangeDetectionStrategy, Component, computed, input, isDevMode } from '@angular/core'
import { ChartFrame } from '../chart-frame/chart-frame'
import { ChartAxis } from '../chart-axis/chart-axis'
import { ChartTooltip, type TooltipPoint } from '../chart-tooltip/chart-tooltip'
import { ChartLegend, type LegendEntry } from '../chart-legend/chart-legend'
import { ChartEmpty } from '../chart-empty/chart-empty'
import { ChartTable } from '../chart-table/chart-table'
import { LineSeries } from './line-series'
import { formatCompact, formatNumber } from '../../primitives'
import type { AxisSpec, LinearAxisSpec } from '../chart-context/chart-context'
import {
  longestSeriesLength,
  numericXDomain,
  timeXDomain,
  yDomain,
  type ChartSeries,
} from '../chart-data/chart-data'

/** Au-delà, la palette cycle et un avertissement est émis en développement. */
const MAX_SERIES = 3

@Component({
  selector: 'gbt-line-chart',
  standalone: true,
  imports: [ChartFrame, ChartAxis, ChartTooltip, ChartLegend, ChartEmpty, ChartTable, LineSeries],
  templateUrl: './line-chart.html',
  styleUrl: './line-chart.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class LineChart<X extends number | Date> {
  series = input.required<ChartSeries<X>[]>()
  xKind = input.required<'linear' | 'time'>()
  locale = input.required<string>()
  /** Nom accessible du graphique. */
  label = input.required<string>()
  /** Légende de la table non visuelle — critère 1.1. */
  tableCaption = input.required<string>()
  /** En-tête de la colonne des abscisses dans la table. */
  xColumn = input.required<string>()
  emptyMessage = input.required<string>()

  area = input(false)
  /** Étend le domaine des ordonnées jusqu'à zéro. Un axe tronqué exagère les variations. */
  yZero = input(true)
  size = input<{ width: number; height: number } | null>(null)

  protected readonly aDesDonnees = computed(() => this.series().some((s) => s.points.length > 0))

  protected readonly pointCount = computed(() => longestSeriesLength(this.series()))

  protected readonly xSpec = computed<AxisSpec>(() =>
    this.xKind() === 'time'
      ? { kind: 'time', domain: timeXDomain(this.series() as ChartSeries<Date>[]) }
      : { kind: 'linear', domain: numericXDomain(this.series() as ChartSeries<number>[]) },
  )

  protected readonly ySpec = computed<LinearAxisSpec>(() => ({
    kind: 'linear',
    domain: yDomain(this.series(), this.yZero()),
  }))

  protected readonly legendEntries = computed<LegendEntry[]>(() =>
    this.series().map((s) => ({ label: s.label, pattern: s.pattern ?? 'solid' })),
  )

  /**
   * Abscisse formatée pour la table et l'infobulle.
   *
   * Le `as number` n'est pas décoratif : TypeScript ne restreint pas un
   * paramètre générique par `instanceof`. Dans la branche `else`, `x` reste
   * de type `X` et non `number`, et l'appel ne compilerait pas sans lui.
   */
  private readonly formatX = (x: X): string =>
    x instanceof Date
      ? new Intl.DateTimeFormat(this.locale(), {
          dateStyle: 'short',
          timeStyle: 'short',
          timeZone: 'UTC',
        }).format(x)
      : formatCompact(x as number, this.locale())

  /** Abscisses distinctes, dans l'ordre — l'index du socle les parcourt. */
  private readonly abscisses = computed<X[]>(() => {
    const longest = this.series().reduce(
      (best, s) => (s.points.length > best.length ? s.points : best),
      [] as ChartSeries<X>['points'],
    )
    return longest.map((p) => p.x)
  })

  protected readonly tooltipPoints = computed<TooltipPoint<X>[]>(() =>
    this.abscisses().map((x, index) => ({
      x,
      header: this.formatX(x),
      rows: this.series().map((s) => ({
        label: s.label,
        value: s.points[index] === undefined ? '—' : formatNumber(s.points[index].y, this.locale()),
      })),
    })),
  )

  protected readonly tableColumns = computed(() => [
    this.xColumn(),
    ...this.series().map((s) => s.label),
  ])

  protected readonly tableRows = computed<(string | number)[][]>(() =>
    this.abscisses().map((x, index) => [
      this.formatX(x),
      ...this.series().map((s) => (s.points[index] === undefined ? '—' : s.points[index].y)),
    ]),
  )

  constructor() {
    // La spec 0.2 l'exige : le composant ne tronque pas en silence et ne lève
    // pas d'exception — il rend ce qu'on lui donne en faisant cycler la
    // palette, et le signale en développement seulement. Un composant qui se
    // comporterait différemment selon le mode de compilation serait pire que
    // le problème qu'il signale.
    if (isDevMode()) {
      queueMicrotask(() => {
        const count = this.series().length
        if (count > MAX_SERIES) {
          console.warn(
            `gbt-line-chart : ${count} séries reçues pour ${MAX_SERIES} couleurs distinguables. La palette cycle.`,
          )
        }
      })
    }
  }
}
```

```typescript
import { ChangeDetectionStrategy, Component, computed, inject, input } from '@angular/core'
import { CHART_CONTEXT } from '../chart-context/chart-context'
import type { BandScale } from '../../primitives'
import type { ChartSeries } from '../chart-data/chart-data'

interface RenderedBar {
  categorie: string
  x: number
  y: number
  largeur: number
  hauteur: number
}

/**
 * Tracé des barres. Composant **projeté** dans `[gbtChartLayer]`, et c'est
 * ce qui lui donne accès au contexte : `gbt-bar-chart` enveloppe le socle et
 * ne pourrait donc pas l'injecter.
 */
@Component({
  selector: 'g[gbtBarSeries]',
  standalone: true,
  imports: [],
  templateUrl: './bar-series.html',
  styleUrl: './bar-series.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: { 'aria-hidden': 'true' },
})
export class BarSeries {
  series = input.required<ChartSeries<string>>()

  private readonly context = inject(CHART_CONTEXT)

  protected readonly barres = computed<RenderedBar[]>(() => {
    const x = this.context.xScale() as BandScale
    const y = this.context.yScale()
    const base = y.map(0)

    return this.series().points.map((point) => {
      const sommet = y.map(point.y)
      return {
        categorie: point.x,
        x: x.map(point.x),
        // Une valeur négative descend sous la ligne de base : le rectangle
        // part alors du zéro et non du sommet.
        y: Math.min(sommet, base),
        largeur: x.bandwidth,
        hauteur: Math.abs(base - sommet),
      }
    })
  })
}
```

```typescript
import { ChangeDetectionStrategy, Component, computed, input } from '@angular/core'
import { ChartFrame } from '../chart-frame/chart-frame'
import { ChartAxis } from '../chart-axis/chart-axis'
import { ChartTooltip, type TooltipPoint } from '../chart-tooltip/chart-tooltip'
import { ChartEmpty } from '../chart-empty/chart-empty'
import { ChartTable } from '../chart-table/chart-table'
import { BarSeries } from './bar-series'
import { formatNumber } from '../../primitives'
import type { AxisSpec, LinearAxisSpec } from '../chart-context/chart-context'
import { yDomain, type ChartSeries } from '../chart-data/chart-data'

/** Part de chaque intervalle laissée en gouttière entre deux barres. */
const BAND_PADDING = 0.2

/**
 * Histogramme à **série unique**. Une seule série ne fait porter aucune
 * information à la couleur — c'est l'axe des catégories qui nomme chaque
 * barre — si bien que le critère 3.1 est satisfait sans second signal. Le
 * type porte la contrainte : on ne peut pas lui passer deux séries.
 *
 * Un histogramme groupé demandera un composant distinct.
 */
@Component({
  selector: 'gbt-bar-chart',
  standalone: true,
  imports: [ChartFrame, ChartAxis, ChartTooltip, ChartEmpty, ChartTable, BarSeries],
  templateUrl: './bar-chart.html',
  styleUrl: './bar-chart.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class BarChart {
  series = input.required<ChartSeries<string>>()
  locale = input.required<string>()
  label = input.required<string>()
  tableCaption = input.required<string>()
  xColumn = input.required<string>()
  emptyMessage = input.required<string>()

  yZero = input(true)
  size = input<{ width: number; height: number } | null>(null)

  protected readonly aDesDonnees = computed(() => this.series().points.length > 0)
  protected readonly pointCount = computed(() => this.series().points.length)

  protected readonly xSpec = computed<AxisSpec>(() => ({
    kind: 'band',
    domain: this.series().points.map((p) => p.x),
    padding: BAND_PADDING,
  }))

  protected readonly ySpec = computed<LinearAxisSpec>(() => ({
    kind: 'linear',
    domain: yDomain([this.series()], this.yZero()),
  }))

  protected readonly tooltipPoints = computed<TooltipPoint<string>[]>(() =>
    this.series().points.map((point) => ({
      x: point.x,
      header: point.x,
      rows: [{ label: this.series().label, value: formatNumber(point.y, this.locale()) }],
    })),
  )

  protected readonly tableColumns = computed(() => [this.xColumn(), this.series().label])

  protected readonly tableRows = computed<(string | number)[][]>(() =>
    this.series().points.map((point) => [point.x, point.y]),
  )
}
```

```typescript
import { ChangeDetectionStrategy, Component, computed, inject, input } from '@angular/core'
import { CHART_CONTEXT } from '../chart-context/chart-context'
import { linePath, type Scale } from '../../primitives'
import type { ChartInterval, ChartSeries } from '../chart-data/chart-data'

interface RenderedBand {
  label: string
  x: number
  largeur: number
}

/**
 * Courbe d'activité et bandes d'intervalles sur un axe temporel commun.
 *
 * Le composant ignore ce que les intervalles représentent : un consommateur
 * y met ses incidents, un autre ses fenêtres de maintenance.
 *
 * Composant **projeté** dans `[gbtChartLayer]` : c'est ce qui lui donne
 * accès au contexte du socle.
 */
@Component({
  selector: 'g[gbtTimelineSeries]',
  standalone: true,
  imports: [],
  templateUrl: './timeline-series.html',
  styleUrl: './timeline-series.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: { 'aria-hidden': 'true' },
})
export class TimelineSeries {
  series = input.required<ChartSeries<Date>>()
  intervals = input.required<ChartInterval[]>()

  private readonly context = inject(CHART_CONTEXT)

  protected readonly hauteur = computed(() => this.context.box().innerHeight)

  protected readonly ligne = computed(() => {
    const x = this.context.xScale() as Scale<Date>
    const y = this.context.yScale()
    return linePath(this.series().points.map((p) => ({ x: x.map(p.x), y: y.map(p.y) })))
  })

  protected readonly bandes = computed<RenderedBand[]>(() => {
    const x = this.context.xScale() as Scale<Date>
    return this.intervals().map((interval) => {
      const debut = x.map(interval.start)
      const fin = x.map(interval.end)
      return {
        label: interval.label,
        x: debut,
        // Une bande de largeur nulle serait invisible sans qu'on sache
        // qu'elle existe ; la table `sr-only` la porte de toute façon.
        largeur: Math.max(1, fin - debut),
      }
    })
  })
}
```
