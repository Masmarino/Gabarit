# Gabarit 0.2 — Tranche 2 : le socle des graphiques — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer le service de contexte, `chart-frame` et cinq briques, sur lesquels les sept graphiques des tranches 3 et 4 s'appuieront.

**Architecture:** Un service fourni par le composant — jamais en racine — publie en signaux la géométrie mesurée et les échelles construites. `chart-frame` reçoit des spécifications d'axe déclaratives, mesure son conteneur, construit les échelles et porte la navigation clavier. Les briques lisent le contexte par injection ; `chart-table`, elle, en est indépendante pour servir aussi les quatre graphiques autonomes.

**Tech Stack:** Angular 22 (standalone, `input()`, `signal()`, `computed()`, `OnPush`), vitest via `@angular/build:unit-test`, `axe-core`, Storybook `@storybook/angular-vite`. Aucune dépendance ajoutée.

**Spec:** `docs/superpowers/specs/2026-08-30-gabarit-0.2-tranche-2-socle-design.md`

## Global Constraints

- **Aucune dépendance runtime nouvelle.** La librairie ne dépend que de `tslib`.
- **Aucune chaîne visible en dur.** Toute chaîne affichée est une entrée de composant : Gabarit n'embarque aucun mécanisme de traduction. Cela vaut aussi pour les chaînes destinées aux lecteurs d'écran — l'audit de la 0.1 en a laissé passer trois, cachées dans un `sr-only` et un `[attr.aria-label]`.
- **La locale est toujours un paramètre**, jamais déduite de l'environnement.
- **Sélecteurs en `gbt-`, classes BEM internes en `gbt-`.** Le préfixe d'une autre application dans le DOM d'un consommateur trahit l'origine de la librairie.
- **`ChangeDetectionStrategy.OnPush`** sur tous les composants, comme les onze de la 0.1.
- **Tous les composants vivent sous `projects/gabarit/src/lib/components/`.** Ce n'est pas cosmétique : `token-usage.spec.ts` ne parcourt que ce répertoire. Un composant placé ailleurs échapperait silencieusement au garde de tokens.
- **Les marques SVG projetées dans `[gbtChartLayer]` s'écrivent avec le préfixe `svg:`** — `<svg:g>`, `<svg:rect>`. Angular résout l'espace de noms SVG **lexicalement, par gabarit** : le `<svg>` du socle vivant dans un fichier séparé, un `<g>` nu échoue à la compilation en `NG8001` (« 'g' is not a known element »). Mesuré par sonde le 30/08/2026. La contrainte vaut pour tout consommateur du socle, pas seulement pour les tests.
- Commits en français, format Conventional Commits.

## Deux ajustements de la spec, imposés par la lecture du dépôt

**1. `y` est restreint aux domaines linéaires.** La spec type `y` en `AxisSpec`, donc potentiellement `band` ou `time`. Mais `yScale` y est typé `Signal<Scale<number>>`, et les trois cartésiens de la tranche 3 ont tous une ordonnée numérique. Une union sur `y` rendrait `yScale().map(v)` pénible à appeler pour rien. `y` prend donc `LinearAxisSpec`. Élargir plus tard ne casserait aucun appelant.

**2. Les briques vivent sous `components/`, pas sous un répertoire `charts/`.** Voir les contraintes globales : le garde de tokens ne parcourt que `components/`.

```typescript
/**
 * Indice de la valeur la plus proche de `target` dans un tableau **trié par
 * ordre croissant**. Sert à retrouver le point sous le curseur ou sous le
 * focus, donc l'infobulle, donc la conformité aux critères 10.13 et 12.11.
 *
 * Numérique et non temporelle : un appelant sur axe de temps passe des
 * `getTime()`. À égalité parfaite entre deux voisins, rend le plus petit
 * indice — sans cette règle, le point sélectionné sauterait de l'un à
 * l'autre selon les hasards de la dichotomie.
 */
export function nearestIndex(sorted: number[], target: number): number {
  // Un tableau vide n'a pas de plus proche voisin. Rendre 0 ferait lire
  // `undefined` à l'appelant en croyant lire une donnée.
  if (sorted.length === 0) return -1

  let low = 0
  let high = sorted.length - 1
  while (low < high) {
    const mid = (low + high) >> 1
    if (sorted[mid] < target) low = mid + 1
    else high = mid
  }

  // `low` est le premier indice dont la valeur atteint ou dépasse la cible.
  // Le plus proche est lui, ou son prédécesseur. `<=` donne le plus petit
  // indice à égalité.
  const previous = low - 1
  if (previous < 0) return low
  return target - sorted[previous] <= sorted[low] - target ? previous : low
}
```

```typescript
// Un `<text>` SVG est du texte, quel que soit le fait qu'on le peigne avec
// `fill`. On ne le détecte que par le sélecteur, et seulement quand `text`
// y est un élément à part entière — pas une sous-chaîne de `.gbt-context`.
const TEXT_FILL_ON_BASE_RE = new RegExp(
  `(?<![\\w-])text(?![\\w-])[^{}]*\\{[^{}]*(?<![\\w-])fill\\s*:\\s*[^;]*var\\(\\s*--[\\w-]+-base\\s*\\)`,
  'g',
)

/** Règles où un `<text>` SVG est rempli avec un token validé à 3:1. */
function textFillOnBaseViolations(content: string): string[] {
  return [...content.matchAll(TEXT_FILL_ON_BASE_RE)].map((m) => m[0])
}
```

```typescript
  readonly height: number
  readonly margin: ChartMargin
  readonly innerWidth: number
  readonly innerHeight: number
}

export type LinearAxisSpec = { kind: 'linear'; domain: [number, number] }

export type AxisSpec =
  | LinearAxisSpec
  | { kind: 'time'; domain: [Date, Date] }
  | { kind: 'band'; domain: string[]; padding?: number }

const EMPTY_BOX: ChartBox = {
  width: 0,
  height: 0,
  margin: { top: 0, right: 0, bottom: 0, left: 0 },
  innerWidth: 0,
  innerHeight: 0,
}

/**
 * Géométrie mesurée et échelles construites, publiées en signaux aux enfants
 * de `gbt-chart-frame`.
 *
 * **Fourni par le composant, jamais en racine.** Deux graphiques sur une même
 * page sont deux instances ; un service `providedIn: 'root'` ferait écraser
 * la géométrie du premier par le second.
 *
 * Le socle construit les échelles parce qu'une échelle a besoin de la plage
 * en pixels, que seul lui connaît après mesure : un graphique ne peut pas
 * construire la sienne avant que le socle ait mesuré.
 */
@Injectable()
export class ChartContext {
  private readonly _box = signal<ChartBox>(EMPTY_BOX)
  private readonly _xSpec = signal<AxisSpec>({ kind: 'linear', domain: [0, 1] })
  private readonly _ySpec = signal<LinearAxisSpec>({ kind: 'linear', domain: [0, 1] })
  private readonly _activeIndex = signal<number | null>(null)

  readonly box = this._box.asReadonly()
  readonly xSpec = this._xSpec.asReadonly()
  readonly ySpec = this._ySpec.asReadonly()
  readonly activeIndex = this._activeIndex.asReadonly()

  /**
   * `xSpec().kind` discrimine cette union — c'est la raison d'être de la
   * publication des deux : appelée seule, elle serait impraticable.
   */
  readonly xScale = computed<Scale<number> | Scale<Date> | BandScale>(() => {
    const spec = this._xSpec()
    const range: [number, number] = [0, this._box().innerWidth]
    if (spec.kind === 'time') return timeScale(spec.domain, range)
    if (spec.kind === 'band') return bandScale(spec.domain, range, spec.padding ?? 0)
    return linearScale(spec.domain, range)
  })

  /** La plage est inversée : un axe des ordonnées croît vers le haut. */
  readonly yScale = computed<Scale<number>>(() =>
    linearScale(this._ySpec().domain, [this._box().innerHeight, 0]),
  )

  /** Appelé par `gbt-chart-frame` seul. */
  setGeometry(box: ChartBox): void {
    this._box.set(box)
  }

  /** Appelé par `gbt-chart-frame` seul. */
  setSpecs(x: AxisSpec, y: LinearAxisSpec): void {
    this._xSpec.set(x)
    this._ySpec.set(y)
  }

  setActiveIndex(index: number | null): void {
    this._activeIndex.set(index)
  }
}
```

```typescript
import {
  ChangeDetectionStrategy,
  Component,
  ElementRef,
  computed,
  effect,
  inject,
  input,
  signal,
} from '@angular/core'
import {
  ChartContext,
  type AxisSpec,
  type ChartMargin,
  type LinearAxisSpec,
} from '../chart-context/chart-context'

/**
 * Marges par défaut, en dur. Les déduire de la largeur réelle des étiquettes
 * demanderait de mesurer du texte, ce que jsdom ne sait pas faire : une
 * valeur fixe et surchargeable est honnête, une mesure qui ne fonctionnerait
 * qu'en navigateur ne le serait pas.
 */
const DEFAULT_MARGIN: ChartMargin = { top: 8, right: 8, bottom: 32, left: 48 }

@Component({
  selector: 'gbt-chart-frame',
  standalone: true,
  imports: [],
  templateUrl: './chart-frame.html',
  styleUrl: './chart-frame.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  providers: [ChartContext],
})
export class ChartFrame {
  /** Nom accessible du graphique. Aucune valeur par défaut : une chaîne en dur ne serait pas traduisible. */
  label = input.required<string>()

  x = input.required<AxisSpec>()
  y = input.required<LinearAxisSpec>()
  margin = input<Partial<ChartMargin>>({})

  /**
   * Taille explicite. Quand elle est fournie, **aucun observateur n'est
   * créé**. Elle sert trois cas : les tests, le rendu serveur — qui n'a pas
   * plus de moteur de mise en page que jsdom — et le consommateur qui
   * connaît déjà ses dimensions.
   */
  size = input<{ width: number; height: number } | null>(null)

  private readonly host = inject(ElementRef<HTMLElement>)
  private readonly context = inject(ChartContext)
  private readonly measured = signal<{ width: number; height: number } | null>(null)

  protected readonly ready = computed(() => this.context.box().innerWidth > 0)

  protected readonly viewBox = computed(() => {
    const b = this.context.box()
    return `0 0 ${b.width} ${b.height}`
  })

  protected readonly innerTransform = computed(() => {
    const m = this.context.box().margin
    return `translate(${m.left},${m.top})`
  })

  constructor() {
    effect(() => {
      const margin = { ...DEFAULT_MARGIN, ...this.margin() }
      const size = this.size() ?? this.measured()
      const width = size?.width ?? 0
      const height = size?.height ?? 0
      this.context.setSpecs(this.x(), this.y())
      this.context.setGeometry({
        width,
        height,
        margin,
        innerWidth: Math.max(0, width - margin.left - margin.right),
        innerHeight: Math.max(0, height - margin.top - margin.bottom),
      })
    })

    effect((onCleanup) => {
      // Taille explicite : rien à observer. Et sans `ResizeObserver` —
      // jsdom, rendu serveur — on ne mesure pas plutôt que de planter.
      if (this.size() || typeof ResizeObserver === 'undefined') return

      const element = this.host.nativeElement
      const observer = new ResizeObserver((entries) => {
        const rect = entries[0]?.contentRect
        if (rect) this.measured.set({ width: rect.width, height: rect.height })
      })
      observer.observe(element)
      onCleanup(() => observer.disconnect())
    })
  }
}
```

```typescript
import { ChangeDetectionStrategy, Component, computed, inject, input } from '@angular/core'
import { ChartContext } from '../chart-context/chart-context'
import { formatCompact, niceTicks, timeTicks, type BandScale, type Scale } from '../../primitives'

interface Tick {
  key: string
  x: number
  y: number
  label: string
  /** Seconde ligne, seulement sur la première graduation de chaque journée. */
  date: string | null
}

@Component({
  selector: 'gbt-chart-axis',
  standalone: true,
  imports: [],
  templateUrl: './chart-axis.html',
  styleUrl: './chart-axis.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: { '[attr.axis]': 'axis()' },
})
export class ChartAxis {
  axis = input.required<'x' | 'y'>()
  locale = input.required<string>()
  tickCount = input(5)
  /** Surcharge du formatage. `null` laisse l'axe choisir selon la sorte de domaine. */
  format = input<((value: never) => string) | null>(null)

  private readonly context = inject(ChartContext)

  protected readonly anchor = computed(() => (this.axis() === 'x' ? 'middle' : 'end'))

  protected readonly groupTransform = computed(() => {
    const box = this.context.box()
    // L'axe des abscisses se pose sous la boîte utile, celui des ordonnées
    // à sa gauche.
    return this.axis() === 'x' ? `translate(0,${box.innerHeight})` : 'translate(0,0)'
  })

  protected readonly ticks = computed<Tick[]>(() =>
    this.axis() === 'x' ? this.xTicks() : this.yTicks(),
  )

  private yTicks(): Tick[] {
    const spec = this.context.ySpec()
    const scale = this.context.yScale()
    const custom = this.format()
    return niceTicks(spec.domain[0], spec.domain[1], this.tickCount()).map((value) => ({
      key: `y-${value}`,
      x: -8,
      y: scale.map(value) + 4,
      label: custom ? custom(value as never) : formatCompact(value, this.locale()),
      date: null,
    }))
  }

  private xTicks(): Tick[] {
    const spec = this.context.xSpec()
    const box = this.context.box()
    const custom = this.format()

    if (spec.kind === 'band') {
      const scale = this.context.xScale() as BandScale
      return spec.domain.map((category) => ({
        key: `x-${category}`,
        x: scale.map(category) + scale.bandwidth / 2,
        y: 20,
        label: custom ? custom(category as never) : category,
        date: null,
      }))
    }

    if (spec.kind === 'time') {
      const scale = this.context.xScale() as Scale<Date>
      const result = timeTicks(spec.domain[0], spec.domain[1], box.innerWidth)
      // La règle de date ne s'applique qu'aux granularités plus fines que la
      // journée : au-delà, l'étiquette porte déjà le jour ou le mois.
      const fine = result.unit === 'hour' || result.unit === 'minute' || result.unit === 'second'
      const days = new Set(result.values.map((v) => v.toISOString().slice(0, 10)))
      const multiDay = days.size > 1
      const seen = new Set<string>()

      return result.values.map((value) => {
        const day = value.toISOString().slice(0, 10)
        // Première graduation de sa journée : elle porte la date. Cela lève
        // l'ambiguïté des minuits, pas celle des heures intermédiaires, qui
        // se lisent parce que le lecteur voit passer la date entre elles.
        const first = fine && multiDay && !seen.has(day)
        seen.add(day)
        return {
          key: `x-${value.getTime()}`,
          x: scale.map(value),
          y: 20,
          label: custom ? custom(value as never) : result.format(value, this.locale()),
          date: first
            ? new Intl.DateTimeFormat(this.locale(), {
                day: '2-digit',
                month: '2-digit',
                timeZone: 'UTC',
              }).format(value)
            : null,
        }
      })
    }

    const scale = this.context.xScale() as Scale<number>
    return niceTicks(spec.domain[0], spec.domain[1], this.tickCount()).map((value) => ({
      key: `x-${value}`,
      x: scale.map(value),
      y: 20,
      label: custom ? custom(value as never) : formatCompact(value, this.locale()),
      date: null,
    }))
  }
}
```

```typescript
import { ChangeDetectionStrategy, Component, input } from '@angular/core'

export interface LegendEntry {
  label: string
  /**
   * Second signal, distinct de la couleur. Le critère 3.1 interdit que
   * l'information passe uniquement par la teinte : sans lui, la légende
   * serait illisible en monochromie, et la limite à trois séries n'y
   * changerait rien.
   */
  pattern?: 'solid' | 'dashed' | 'dotted'
}

const DASH_ARRAYS: Record<NonNullable<LegendEntry['pattern']>, string> = {
  solid: '',
  dashed: '6 3',
  dotted: '1 3',

@Component({

  styleUrl: './chart-legend.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class ChartLegend {
  entries = input.required<LegendEntry[]>()

  protected dashArray(pattern: LegendEntry['pattern']): string {
    return DASH_ARRAYS[pattern ?? 'solid']
  }
}
```
