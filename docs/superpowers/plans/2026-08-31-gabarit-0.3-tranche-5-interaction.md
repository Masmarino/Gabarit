# Gabarit 0.3 — Tranche 5 : l'interaction et le rendu — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre les sept graphiques de Gabarit sensibles au pointeur et leur donner le rendu d'un design system plutôt que d'un portage.

**Architecture:** Le socle `gbt-chart-frame` possède déjà `activeIndex` dans son `ChartContext`, alimenté par la navigation clavier. Le pointeur alimente **le même signal** : souris et clavier partagent un chemin de code unique, et le critère RGAA 10.13 cesse d'être satisfait par le vide. Les quatre graphiques autonomes n'ont pas de socle et n'en ont pas besoin — leurs éléments sont discrets, on les survole directement.

**Tech Stack:** Angular 22 (standalone, `input()`, `computed()`, `OnPush`), vitest via `@angular/build:unit-test`, `axe-core`, Storybook `@storybook/angular-vite`. Aucune dépendance ajoutée.

**Spec:** `docs/superpowers/specs/2026-08-31-gabarit-0.3-interaction-et-rendu-design.md`

## Global Constraints

- **Aucune dépendance runtime nouvelle.** La librairie ne dépend que de `tslib`.
- **Aucune chaîne visible en dur.** Toute chaîne affichée est une entrée de composant, y compris celles destinées aux lecteurs d'écran.
- **La locale est toujours un paramètre**, jamais déduite de l'environnement.
- **Aucune fonction de formatage dans l'API.** Les valeurs non numériques se passent déjà formatées, comme `gbt-gauge-bar.formattedValue`.
- **Sélecteurs en `gbt-`, classes BEM internes en `gbt-`.**
- **`ChangeDetectionStrategy.OnPush`** sur tous les composants.
- **Tous les composants vivent sous `projects/gabarit/src/lib/components/`** — `token-usage.spec.ts` ne parcourt que ce répertoire.
- **Un token `*-base` ne peint jamais de texte.** Un aplat HTML purement graphique y déroge par le marqueur `// token-graphique-sans-texte` en fin de ligne, jamais sur `color`, `border-color` ni `outline-color`, et **une seule déclaration éligible par ligne marquée**.
- **Les couleurs se posent en CSS, jamais en attribut de présentation SVG.** Un `stroke="var(--x)"` ne résout pas la variable et sort noir.
- **Les éléments SVG d'un gabarit sans balise `<svg>` dans le même fichier portent le préfixe `svg:`** — sinon `NG8001`. `chart-frame.html` en contient une : ses éléments n'en ont pas besoin. `line-series.html`, `bar-series.html` et `chart-axis.html` n'en contiennent pas : les leurs en ont besoin.
- **Aucun identifiant accentué dans une expression de gabarit** — le lexer d'Angular les rejette (`NG5002`). Les commentaires et intitulés de test restent accentués.
- **Un bloc `@if` qui projette dans une fente nommée n'a qu'un seul nœud racine** — au-delà, `NG8011` et le contenu n'est pas projeté du tout.
- **Parité clavier obligatoire.** Tout état atteignable au pointeur est atteignable au clavier, et un test le prouve.
- **jsdom n'a ni mise en page ni mesure de texte.** `getBoundingClientRect()` y rend des zéros : tout test de pointeur doit le remplacer explicitement, sans quoi il mesure le vide en ayant l'air juste.
- Commits en français, format Conventional Commits.

```typescript
  private readonly _pointValues = signal<PointValue[]>([])
  readonly pointValues = this._pointValues.asReadonly()

  /**
   * Positions en pixels de chaque abscisse, dans le repère de la boîte
   * utile. Sur un domaine catégoriel, le **centre** de la bande : une barre
   * se survole en son milieu, pas sur son bord gauche.
   */
  readonly pointPositions = computed<number[]>(() => {
    const kind = this._xSpec().kind
    const scale = this.xScale()
    return this._pointValues().map((value) =>
      kind === 'band'
        ? (scale as BandScale).map(value as string) + (scale as BandScale).bandwidth / 2
        : (scale as Scale<number> | Scale<Date>).map(value as never),
    )
  })

  readonly activePosition = computed<number | null>(() => {
    const index = this._activeIndex()
    if (index === null) return null
    return this.pointPositions()[index] ?? null
  })

  setPointValues(values: PointValue[]): void {
    this._pointValues.set(values)
  }
```

```typescript
  protected onPointerMove(event: PointerEvent | MouseEvent): void {
    const positions = this.context.pointPositions()
    if (positions.length === 0) return

    // `clientX` moins le bord gauche de la surface, moins la marge : le
    // `viewBox` vaut exactement la taille mesurée, donc une unité SVG est
    // un pixel et aucune mise à l'échelle n'entre en jeu.
    const rect = (event.currentTarget as HTMLElement).getBoundingClientRect()
    const local = event.clientX - rect.left - this.context.box().margin.left

    this.context.setActiveIndex(nearestIndex(positions, local))
  }

  protected onPointerLeave(event: PointerEvent | MouseEvent): void {
    // Le clavier prime : sortir la souris ne doit pas effacer l'état qu'un
    // utilisateur aux flèches vient d'établir sur une surface focalisée.
    const surface = event.currentTarget as HTMLElement
    if (surface.ownerDocument.activeElement === surface) return
    this.context.setActiveIndex(null)
  }
```

**Interfaces:**

```typescript
interface ActiveDot {
  x: number
  y: number
  couleur: number
}
```

```typescript
  /**
   * Pastilles du point actif, une par série qui a réellement une valeur à
   * cette abscisse. `activeIndex` désigne un rang dans les abscisses
   * **fusionnées** du graphe : indexer `serie.points` par ce rang placerait
   * la pastille d'une série courte sur l'ordonnée d'un autre point.
   */
  protected readonly pastilles = computed<ActiveDot[]>(() => {
    const index = this.context.activeIndex()
    if (index === null) return []
    const abscisse = this.context.pointValues()[index]
    if (abscisse === undefined) return []

    const cle = abscisse instanceof Date ? abscisse.getTime() : abscisse
    const x = this.context.xScale() as Scale<never>
    const y = this.context.yScale()

    const dots: ActiveDot[] = []
    this.series().forEach((serie, index) => {
      const point = serie.points.find(
        (p) => (p.x instanceof Date ? p.x.getTime() : p.x) === cle,
      )
      if (point === undefined) return
      dots.push({ x: x.map(point.x as never), y: y.map(point.y), couleur: (index % 3) + 1 })
    })
    return dots
  })
```

```typescript
 * Marge verticale, en pixels. Le rayon de la pastille active, plus la
 * moitié de l'épaisseur du trait : sans elle, le point le plus haut se
```

```typescript
  emptyMessage = input.required<string>()

  protected readonly indexActif = signal<number | null>(null)

  private readonly echelles = computed(() => {
    const values = this.values()
    const min = Math.min(...values)
    const max = Math.max(...values)
    return {
      x: linearScale([0, Math.max(values.length - 1, 0)], [0, this.width()]),
      y: linearScale([min, max], [this.height() - MARGE, MARGE]),
    }
  })

  protected readonly chemin = computed(() => {
    const values = this.values()
    if (values.length === 0) return null
    const { x, y } = this.echelles()
    return linePath(values.map((valeur, index) => ({ x: x.map(index), y: y.map(valeur) })))
  })

  protected readonly positions = computed<number[]>(() => {
    const { x } = this.echelles()
    return this.values().map((_, index) => x.map(index))
  })

  protected readonly pastille = computed<{ x: number; y: number } | null>(() => {
    const index = this.indexActif()
    if (index === null) return null
    const valeur = this.values()[index]
    if (valeur === undefined) return null
    const { x, y } = this.echelles()
    return { x: x.map(index), y: y.map(valeur) }
  })

  protected readonly infobulle = computed<string | null>(() => {
    const index = this.indexActif()
    if (index === null) return null
    const valeur = this.values()[index]
    if (valeur === undefined) return null
    return `${formatNumber(index + 1, this.locale())} · ${formatNumber(valeur, this.locale())}`
  })

  protected onPointerMove(event: PointerEvent | MouseEvent): void {
    const positions = this.positions()
    if (positions.length === 0) return
    const rect = (event.currentTarget as Element).getBoundingClientRect()
    this.indexActif.set(nearestIndex(positions, event.clientX - rect.left))
  }

  protected onPointerLeave(event: PointerEvent | MouseEvent): void {
    const cible = event.currentTarget as Element
    if (cible.ownerDocument.activeElement === cible) return
    this.indexActif.set(null)
  }

  protected onKeydown(event: KeyboardEvent): void {
    const dernier = this.values().length - 1
    if (dernier < 0) return
    const courant = this.indexActif()
    switch (event.key) {
      case 'ArrowRight':
        this.indexActif.set(courant === null ? 0 : Math.min(dernier, courant + 1))
        break
      case 'ArrowLeft':
        this.indexActif.set(courant === null ? dernier : Math.max(0, courant - 1))
        break
      case 'Home':
        this.indexActif.set(0)
        break
      case 'End':
        this.indexActif.set(dernier)
        break
      case 'Escape':
        this.indexActif.set(null)
        break
      default:
        return
    }
    event.preventDefault()
  }
```
