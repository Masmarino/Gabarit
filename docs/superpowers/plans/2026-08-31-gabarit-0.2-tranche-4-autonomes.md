# Gabarit 0.2 — Tranche 4 : les quatre autonomes — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer les quatre derniers graphiques de la couche dataviz, solder trois dettes des tranches précédentes, et clore la 0.2.

**Architecture:** Un seul des quatre est un tracé — `gbt-sparkline`, en SVG, avec `linearScale` et `linePath`. Les trois autres sont des largeurs proportionnelles et se rendent en HTML et CSS : un `viewBox` mis à l'échelle y étirerait le texte des libellés. Aucun des quatre n'emploie `gbt-chart-frame` : ils n'ont pas d'axes.

**Tech Stack:** Angular 22 (standalone, `input()`, `computed()`, `OnPush`), vitest via `@angular/build:unit-test`, `axe-core`, Storybook `@storybook/angular-vite`. Aucune dépendance ajoutée.

**Spec:** `docs/superpowers/specs/2026-08-31-gabarit-0.2-tranche-4-autonomes-design.md`

## Global Constraints

- **Aucune dépendance runtime nouvelle.** La librairie ne dépend que de `tslib`.
- **Aucune chaîne visible en dur.** Toute chaîne affichée est une entrée de composant, y compris celles destinées aux lecteurs d'écran. L'audit de la 0.1 en a laissé passer trois, cachées dans un `sr-only` et un `[attr.aria-label]`.
- **La locale est toujours un paramètre**, jamais déduite de l'environnement.
- **Sélecteurs en `gbt-`, classes BEM internes en `gbt-`.**
- **`ChangeDetectionStrategy.OnPush`** sur tous les composants.
- **Tous les composants vivent sous `projects/gabarit/src/lib/components/`** — `token-usage.spec.ts` ne parcourt que ce répertoire.
- **Un token `*-base` ne peint jamais de texte.** Les couleurs de série sont validées à 3:1 ; un garde les refuse sur toute règle dont le sélecteur désigne du texte, `fill` comme `stroke`.
- **Les couleurs se posent en CSS, jamais en attribut de présentation SVG.** Un `stroke="var(--x)"` ne résout pas la variable et sort noir.
- **Les éléments SVG d'un gabarit sans balise `<svg>` dans le même fichier portent le préfixe `svg:`** — sinon `NG8001`.
- **Aucun identifiant accentué dans une expression de gabarit** — le lexer d'Angular les rejette (`NG5002`). Les commentaires et intitulés de test, eux, restent accentués.
- **Un bloc `@if` qui projette dans une fente nommée n'a qu'un seul nœud racine** — au-delà, `NG8011` et le contenu n'est pas projeté du tout. Aucune tâche de cette tranche ne projette, mais la règle vaut si l'une venait à le faire.

````markdown
### Assembler son propre graphique

`gbt-chart-frame` et ses briques sont exposés pour qu'un consommateur
puisse construire un graphique que Gabarit ne fournit pas. L'`AxisSpec`
qu'il passe au socle doit alors respecter deux contraintes, faute de quoi
la géométrie sort du cadre **sans le moindre avertissement** :

- **Ses bornes doivent être des graduations.** `gbt-chart-axis` gradue par
  `niceTicks`, qui étend le domaine aux valeurs rondes ; si l'échelle
  projette un domaine brut, la graduation extrême tombe hors du cadre — 78
  px au-delà du bord droit sur un domaine de 0 à 63, mesuré.
- **Le domaine des ordonnées d'un histogramme doit contenir zéro**, sans
  quoi la ligne de base se projette hors de la boîte utile et les
  rectangles traversent l'axe.

`niceXDomain` et `niceYDomain` sont exportées pour cela :

```typescript
const x = { kind: 'linear', domain: niceXDomain(series, 5) }
const y = { kind: 'linear', domain: niceYDomain(series, true, 5) }
```
````

Le troisième argument de chacune est le nombre visé de graduations : passez
la même valeur à `gbt-chart-axis` par son entrée `tickCount`, sans quoi les
deux calculs divergent.


```typescript
/**
 * Largeur estimée d'un caractère pour la police d'axe, à 0,75rem — soit
 * 12 px. C'est une **estimation**, pas une mesure : jsdom n'a pas de moteur
 * de mise en page, et la tranche 2 a refusé une mesure qui ne
 * fonctionnerait qu'en navigateur. Une police très large ou très étroite
 * met donc la règle en défaut.
 */
const ESTIMATED_CHAR_WIDTH = 6.5

/** Écart minimal souhaité entre deux étiquettes de catégories voisines. */
const LABEL_GAP = 8
```

et remplacer la branche `band` de `xTicks()` par :

```typescript
if (spec.kind === 'band') {
  const scale = this.context.xScale() as BandScale
  // Les axes linéaire et temporel s'éclaircissent d'eux-mêmes, par
  // `niceTicks` et `timeTicks`. Celui-ci affichait toutes ses
  // catégories : sept se chevauchaient à 320 px. On en garde une sur
  // `k`, le plus petit entier tel que `k` pas valent au moins la
  // largeur estimée de la plus longue étiquette, plus une gouttière.
  //
  // Les catégories masquées restent dans la table `sr-only` du
  // graphique : c'est ce qui rend l'éclaircissement acceptable.
  const step = spec.domain.length === 0 ? 0 : box.innerWidth / spec.domain.length
  const widest = spec.domain.reduce(
    (large, category) => Math.max(large, category.length * ESTIMATED_CHAR_WIDTH),
    0,
  )
  const keepEvery = Math.max(1, Math.ceil((widest + LABEL_GAP) / Math.max(step, 1)))

  return spec.domain
    .map((category) => ({
      key: `x-${category}`,
      x: scale.map(category) + scale.bandwidth / 2,
      y: 20,
      label: custom ? custom(category as never) : category,
      date: null,
      anchor: 'middle' as const,
    }))
    .filter((_, index) => index % keepEvery === 0)
}
```

Le `filter` vient **après** le `map` pour que `index` soit celui de la catégorie, et non celui d'une liste déjà réduite.

`sparkline.ts` :

```typescript
import { ChangeDetectionStrategy, Component, computed, input } from '@angular/core'
import { ChartTable } from '../chart-table/chart-table'
import { formatNumber, linePath, linearScale } from '../../primitives'

/**
 * Micro-courbe sans axe, destinée à une cellule de tableau ou à une tuile.
 *
 * Elle prend des **valeurs nues** et non des points : son abscisse est le
 * rang, et exiger `{ x, y }` obligerait chaque appelant à inventer des
 * abscisses qui ne seraient jamais affichées.
 *
 * Sa taille est fixe et non mesurée : elle vit dans une cellule de tableau,
 * où poser un `ResizeObserver` par ligne coûterait cher pour une largeur que
 * le consommateur connaît déjà.
 */
@Component({
  selector: 'gbt-sparkline',
  standalone: true,
  imports: [ChartTable],
  templateUrl: './sparkline.html',
  styleUrl: './sparkline.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class Sparkline {
  values = input.required<number[]>()
  /** Nom accessible, employé comme légende de la table non visuelle. */
  label = input.required<string>()
  xColumn = input.required<string>()
  yColumn = input.required<string>()
  locale = input.required<string>()

  width = input(80)
  height = input(24)

  protected readonly viewBox = computed(() => `0 0 ${this.width()} ${this.height()}`)

  protected readonly colonnes = computed(() => [this.xColumn(), this.yColumn()])

  protected readonly lignes = computed<(string | number)[][]>(() =>
    this.values().map((valeur, index) => [
      formatNumber(index + 1, this.locale()),
      formatNumber(valeur, this.locale()),
    ]),
  )

  protected readonly chemin = computed(() => {
    const values = this.values()
    if (values.length === 0) return null

    // Domaine plat — une seule valeur, ou toutes égales : `linearScale` le
    // gère en projetant au début de la plage, sans diviser par zéro.
    const min = Math.min(...values)
    const max = Math.max(...values)
    const y = linearScale([min, max], [this.height(), 0])
    // Une valeur unique n'a pas de rang à parcourir : l'échelle des
    // abscisses est alors plate elle aussi.
    const x = linearScale([0, Math.max(values.length - 1, 0)], [0, this.width()])

    return linePath(values.map((valeur, index) => ({ x: x.map(index), y: y.map(valeur) })))
  })
}
```

```typescript
/**
 * Barre de capacité à seuil — « stockage employé sur total », « connexions
 * actives sur maximum ». La teinte du remplissage bascule aux seuils, mais
 * **la couleur ne porte rien que le texte ne dise** : le libellé de sévérité
 * s'affiche en toutes lettres à côté de la valeur, ce qui satisfait le
 * critère 3.1.
 *
 * Pas de table `sr-only` : `role="progressbar"` est la sémantique exacte de
 * ce composant, et sa valeur est déjà lisible en texte. Une table
 * dupliquerait l'annonce.
 */
@Component({
  selector: 'gbt-gauge-bar',
  standalone: true,
  imports: [],
  templateUrl: './gauge-bar.html',
  styleUrl: './gauge-bar.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class GaugeBar {
  value = input.required<number>()
  max = input.required<number>()
  label = input.required<string>()
  /** Valeur déjà formatée — « 62 Go / 100 Go ». Une chaîne, pas une fonction. */
  formattedValue = input.required<string>()
  warningLabel = input.required<string>()
  criticalLabel = input.required<string>()

  /** Seuils en pourcentage. Ceux de l'application d'origine par défaut. */
  thresholds = input<{ warning: number; critical: number }>({ warning: 70, critical: 90 })

  protected readonly pourcentage = computed(() => {
    const max = this.max()
    // Un maximum nul rendrait `NaN%`, que le navigateur ignore : la barre
    // resterait vide sans qu'on sache pourquoi.
    if (max <= 0) return 0
    return Math.max(0, Math.min(100, (this.value() / max) * 100))
  })

  protected readonly severite = computed<'warning' | 'critical' | null>(() => {
    const pourcentage = this.pourcentage()
    const { warning, critical } = this.thresholds()
    if (pourcentage >= critical) return 'critical'
    if (pourcentage >= warning) return 'warning'
    return null
  })

  protected readonly severiteLibelle = computed(() => {
    const severite = this.severite()
    if (severite === 'critical') return this.criticalLabel()
    if (severite === 'warning') return this.warningLabel()
    return null
  })
}
```

```typescript
  label: string
  value: number
}

interface RenderedRow {
  label: string
  valeur: string
  /** Largeur de la barre de fond, en pourcentage de la plus grande valeur. */
  part: number
}

/**
 * Palmarès par dimension — « top navigateurs », « top pages » —, rendu en
 * **vraie table visible**.
 *
 * Ces données sont tabulaires : une table donne gratuitement à un lecteur
 * d'écran les en-têtes de colonne et l'association cellule-en-tête qu'une
 * liste lui refuserait. Elle n'a donc pas de table `sr-only` : en ajouter
 * une masquée ferait annoncer le palmarès deux fois.

@Component({
  selector: 'gbt-dimension-card',
  standalone: true,
  imports: [],
  templateUrl: './dimension-card.html',
  styleUrl: './dimension-card.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class DimensionCard {
  rows = input.required<DimensionRow[]>()
  caption = input.required<string>()
  labelColumn = input.required<string>()
  valueColumn = input.required<string>()
  emptyMessage = input.required<string>()
  locale = input.required<string>()

  protected readonly lignes = computed<RenderedRow[]>(() => {
    const rows = this.rows()
    const plusGrande = rows.reduce((max, row) => Math.max(max, row.value), 0)
    return rows.map((row) => ({
      label: row.label,
      valeur: formatNumber(row.value, this.locale()),

      // comparaison entre lignes, pas une part d'un ensemble. Un maximum
      // nul rendrait `NaN%`, que le navigateur ignore.
      part: plusGrande <= 0 ? 0 : (row.value / plusGrande) * 100,
    }))
  })
```

`funnel-chart.ts` :

```typescript
import { ChangeDetectionStrategy, Component, computed, input } from '@angular/core'
import { ChartTable } from '../chart-table/chart-table'
import { formatNumber, formatPercent } from '../../primitives'

export interface FunnelStep {
  label: string
  value: number
}

interface RenderedStep {
  label: string
  valeur: string
  /** Largeur du bandeau, en pourcentage de la première étape. */
  part: number
}

/**
 * Entonnoir de conversion : des étapes ordonnées dont la largeur décroît, et
 * dont le décrochage se lit dans l'écart des largeurs.
 *
 * Rendu en HTML et CSS, non en SVG : des étapes empilées à largeur
 * proportionnelle sont de la mise en page, et un `viewBox` mis à l'échelle
 * étirerait le texte des libellés.
 *
 * Il porte en revanche une table `sr-only` : une largeur ne dit rien à qui
 * ne la voit pas, et le taux de conversion n'est écrit nulle part ailleurs.
 */
@Component({
  selector: 'gbt-funnel-chart',
  standalone: true,
  imports: [ChartTable],
  templateUrl: './funnel-chart.html',
  styleUrl: './funnel-chart.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class FunnelChart {
  steps = input.required<FunnelStep[]>()
  label = input.required<string>()
  locale = input.required<string>()
  emptyMessage = input.required<string>()
  tableCaption = input.required<string>()
  stepColumn = input.required<string>()
  valueColumn = input.required<string>()
  conversionColumn = input.required<string>()

  /** Valeur de la première étape, référence de toutes les proportions. */
  private readonly reference = computed(() => this.steps()[0]?.value ?? 0)

  protected readonly etapes = computed<RenderedStep[]>(() => {
    const reference = this.reference()
    return this.steps().map((step) => ({
      label: step.label,
      valeur: formatNumber(step.value, this.locale()),
      // Une première étape nulle rendrait `NaN%` pour toutes les suivantes,
      // que le navigateur ignore : les bandeaux disparaîtraient en silence.
      part: reference <= 0 ? 0 : (step.value / reference) * 100,
    }))
  })

  protected readonly colonnes = computed(() => [
    this.stepColumn(),
    this.valueColumn(),
    this.conversionColumn(),
  ])

  protected readonly lignes = computed<(string | number)[][]>(() => {
    const reference = this.reference()
    return this.steps().map((step) => [
      step.label,
      formatNumber(step.value, this.locale()),
      formatPercent(reference <= 0 ? 0 : step.value / reference, this.locale()),
    ])
  })
}
```
